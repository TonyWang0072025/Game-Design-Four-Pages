# 游戏设计四页总览
**Game Design Four Pages** · [English](README.en.md) · [MIT](LICENSE)

用四份简明、可持续维护的文档，帮助游戏开发者对齐方向、评审功能、理解玩法和检查资源取舍。适合个人开发者与团队，既可用作AI Skill，也可手动使用。

> **v0.1.0：首个公开版本。** 已有一次独立的早期项目试用，仍需更多类型、规模与工具的实际验证。它辅助设计思考，不能保证游戏好玩或数值平衡。

## 四页分别解决什么？

| 文档 | 核心问题 | 推荐表达 |
| --- | --- | --- |
| 🧭 游戏愿景 | 我们在做什么游戏？ | 一句到一段，说明体验与区别 |
| 🛡️ 设计支柱 | 哪些原则必须守住？ | 3—5条能影响实际取舍的原则 |
| 🔁 游戏循环 | 玩家反复做什么？ | 动作框与时间、因果箭头 |
| ⚖️ 资源流 | 玩家投入、交换和获得什么？ | 资源节点与转换关系 |

**设计支柱与玩法系统不同。** “战斗、经营、养成”是系统；“每次失败都能学到新的应对方法”才是可供评审的原则候选。

## 第一次使用

把游戏想法、已确认的决定与未决问题提供给AI，然后说：

> 使用 game-design-four-pages，为我的游戏建立“四页设计总览”。先读取这些资料，区分已确认、暂定、提案和缺失；用简体中文、流程图和表格呈现，不补造机制与数值。

已有项目可以这样调用：

> 根据最新GDD和本轮决定更新四页总览。检查这个新功能支持哪些设计支柱、与哪些原则冲突，并标出需要试玩验证的问题。

没有AI工具也能使用：[打开四页模板](templates/README.md)，手动填写与评审即可。

## 安装与兼容性

可安装目录是 [skills/game-design-four-pages](skills/game-design-four-pages/SKILL.md)。下载或克隆本仓库后，在支持Skill的工具中要求安装此目录；按该工具自己的安装流程操作，避免覆盖已有同名技能。

部分Codex环境支持显式调用 `$game-design-four-pages`。其他环境可能需要在界面中选择技能，或直接读取SKILL.md及其引用文件。**本项目未验证所有AI产品的自动安装与调用**；仅把文件上传到聊天，也不等于安装完成。

本项目不需要API密钥、后台服务或自动安装脚本。AI使用额度按你所用平台的规则计费。

## 在开发全过程中使用

| 阶段 | 重点 | 需要守住的边界 |
| --- | --- | --- |
| 灵感与立项 | 愿景、候选支柱、粗循环 | 资料不足就保留未知，资源流可暂缺或标为概念 |
| 原型 | 对照实际操作修正循环 | 区分想做、已决定与已实现 |
| 首次可玩之后 | 建立反映实际机制的资源流 | 清楚标注未实现部分 |
| 内容制作 | 用支柱筛选新功能与内容 | 详细规则继续维护在GDD |
| 测试与迭代 | 检查偏移、反馈与资源瓶颈 | 图表提出假设，试玩验证结论 |
| 交接与维护 | 四页先建立共同语境 | 更新来源版本与详细资料链接 |

## 方法来源与许可证

受Ian Schreiber在GDC 2025的讲座 *The Four One-Page Design Docs You Need (And How to Use Them)* 启发。本项目把方法转化为AI协作流程、中文使用说明、模板和验收要求，**不是讲者或GDC的官方项目**。

原创工作流、文档和示例采用MIT许可证。原讲座视频、字幕、幻灯片及其他第三方内容不在本项目许可范围内，也不随仓库再分发。四页总览需要与详细GDD配合使用。
